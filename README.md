## 🚀 Featured Project — InterviewPro

> **An AI-powered Android app that gives real-time, quantified feedback on your interview delivery.**
> No more guessing — just numbers.

| What it does | How |
|---|---|
| 😊 Detects facial expressions & eye contact | Google ML Kit (on-device) |
| 🎙️ Measures speech rate & filler words | Android SpeechRecognizer + OpenAI Whisper |
| 📈 Tracks weekly improvement | Firebase Firestore + MPAndroidChart |
| 🔐 Secure user accounts & session storage | Firebase Auth + Firebase Storage |
